# PR-05：最终 Stats 快照与按需序列化

2026-11-03。状态：IN_PROGRESS。基线 `4f053afe240a3313d0c5289660936325c1cc8508`；对应 M5。

## 范围与成功标准

保留 PR-01 的设备迭代和现有发布边界，只将最终 residual、cloth/cable reactions 的即时 Python list 转换改为独立、只读、原生精度 NumPy 快照。CPU `.numpy()` 可能共享存储，因此必须复制；不得让旧 Stats 引用下一步会覆盖的 solver scratch。不新增公共开关、惰性容器或第二套序列化器。最终 D2H 次数和字节不因本改动减少。

1. 正常与停止发布保留最终候选的 residual/reactions；迭代失败保留最后一次已报告的 residual，尚无报告则没有该字段；发布后段失败可以保留被回滚候选的 reactions，结合 `rolled_back` 和 `step_generation` 解读。进入迭代前拒绝输入不替换旧 Stats。
2. 保存 Stats 后运行下一步、失败步和覆盖工作区，旧向量保持不变、禁止原地写入。
3. `monolithic_recording.serial/save` 已支持 ndarray，导出仍为原 JSON 列表，非有限值仍为 null。两个材料 runner 保留 `failure-stats.txt` 并新增完整 `failure-stats.json`，避免 NumPy repr 截断被回滚候选的诊断。
4. 分别测量无导出、真实 `json.dumps(serial(stats), allow_nan=False)` 的完整 step，以及隔离快照阶段；报告主机保留/峰值分配、JSON 字节与完整向量回读，不能隐藏转移到导出的成本。
