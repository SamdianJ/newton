## 实现与生命周期

L1 在构造或首次绑定时登记字段名：owner/material/PCG 在构造时，state/contact batch 在首次绑定时。热路径读取当前数组并保留 shape/dtype/device 等检查；graph key 继续包含存储地址、strides、layout、模式和 stream。合法 owner 存储替换会重新捕获，旧图持有其原存储引用；PCG 固定存储替换仍拒绝。没有缓存整份 `_buffers`，其中仍有真实状态几何工作。消除属性扫描不等于消除绑定验证或保证所有元数据方法更快。

L2 使用稳定原生精度设备存储承载 dt、alpha、inverse-dt-squared 和 contact falloff，在捕获外更新数值。相应 kernel 保留独立 objective 的标量调用，数值不再构成 graph 身份键；不新增版本键，不扩大 LRU。新参数有效载荷合计 FP32 16 B / FP64 32 B。

保留原舍入与错误边界：host dt 先转 Python float 再比较；tet 逆平方有效性仅在有 tet 的 assemble 阶段检查；cloth/cable predictor 仍使用字面量 alpha=0。strided 原生标量输出的有限值检查读取本轮数组，避免计算前复制旧 NaN。离线 workload snapshot 不再独立恢复派生 falloff，避免与主机数值缓存失配。没有公共 API、物理门槛、预算、控制或冻结输入变更；单 stream、非重入约束及 PR-04 首捕获同步防护保持。
