## 判断依据与限制

13 个真实矩阵的 195 个 production graph 组合通过独立残差检查，130 项 CPU/CUDA 投影与 apply 对照通过，但迭代减少未转化为稳定总耗时收益。同处 P0 的第二轮，MAS16 在 tet5/6 的总耗时分别增加约 7.2%/12.3%；首轮 tet6 电源状态不匹配，不作提速依据。本结论限定于当前场景和实现，不推断 MAS 在所有规模下无效。

24 条先导轨迹中 21 条完成；第二轮 Sharpa r3 的基线、local4、MAS16 均有外层失败。MAS32 diagnostic 在 CPU/CUDA 接触回归中停滞。末态差异仍未标定，未宣称所有候选精度或事务准入通过；原始失败保留。性能预算未冻结，未开展正式五次重复，因此此处是研究收尾决定，不是按冻结预算作出的正式性能 NO_GO。

## P3 后续方向

SA-AMG 在离线共享矩阵中明显减少迭代，具有端到端提升的潜力，转入 P3 考虑。当前证据仅为 CPU 数值与成本，AMG GPU 为 `NOT_MEASURED`，不能宣布 GPU 提速或准入通过。

P3 如启动该方向，复用已认证矩阵与隔离 SA-AMG 对照，先评估 GPU 实现及建层、数值更新、apply、PCG、重试的完整成本，再冻结性能预算并验证轨迹精度与稳健性。P2 留存的接触失败、电源状态和末态标定问题作为后续验证输入。本决定不自动启动 P3 实现。
