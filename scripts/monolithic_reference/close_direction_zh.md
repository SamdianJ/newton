## 为什么当前近似会失效

对单个法向接触，令 N 为法向力大小，G 为单位法线到 q/x 的投影行，则残差为 r_n=-GᵀN。其方向导数包含：

`D r_n[δ] = -Gᵀ D N[δ] - (D G[δ])ᵀ N`。

当前 `contact.py` 的 normal factor 主要保留正半定的 `κ GᵀG`，没有后一项。在精确距离场的局部近似下，它对应接触法线曲率及几何映射的变化。归一化插值梯度也不保证标量距离梯度恰好是单位长度，需与曲率项分开审查。

摩擦还依赖 `cap=mu*N`、法线投影、history 转运、相对运动和 q 映射。当前局部 Huber PSD 切线冻结了其中部分量。分解探针通过仅在反事实 kernel 调用中置 mu=0 分离法向残差；原始轨迹和所有实际修正方向的验收仍保留摩擦。摩擦载荷分量使用中心滑移支路及冻结力投影，余项包含切向方向、history、映射及可能的支路变化，不把余项全部解释成 history。

补充分解复跑在位置 24 的第 1395 步终止：h=1/8 时摩擦总贡献 +3.114e-12，其中载荷依赖为 +1.648e-12，其余为 +1.466e-12；法线/映射项为 +2.420e-11，有效法向 key 不变。此结果支持法线与摩擦载荷两个缺项同时存在；不把该终止点的比例套用到第 1436 步。

一个无需摩擦或 SDF 插值的反例：二维半径 1 的圆，位置 (0.5,0)，法向刚度 10，惯性切线 I，外载荷使当前残差为 (0,1)。法向 GN 加惯性得到 diag(11,1)，真实 Jacobian 为 diag(11,-9)。PCG 方向 (0,-1) 的预测 F 导数是 -1，真实导数却是 +9。给 GN 矩阵加正的对角 regularization 只缩小该方向，不会改变上升符号。说明单靠连续法线、增大 PCG 预算或增加 regularization 不能保证解决这一类问题。

对所有 1052 个自由度执行双侧 FD；q 扰动为 2e-4、1e-4，x 扰动为 2e-6、1e-6 米，分母使用实际可表示的 FP32 坐标增量。在线性代数阶段用 FP64 least-squares 解完整非对称系统，只作为终止状态 oracle。

- 位置 18：两档矩阵相对非对称性约 11.9%；对称部分最小特征值约 -0.735。原 merit 1.826e-5，完整方向 alpha=1 后约 1.076e-5，满足原 line search。
- 位置 24：相对非对称性约 11.1%；对称部分最小特征值为 -1.252 / -1.081。原 merit 3.607e-5，alpha=0.5 后约 2.867e-5 / 2.883e-5，满足原 line search，min(detF) 约 0.791。
- 验证后 accepted 坐标与 committed history 未变化。这只是可接受的单次反事实试探，q/global/x 外层收敛与完整 Close 均未因此通过。

以上 Jacobian 含 FD 误差，不能称为解析精确矩阵；两档一致支持方向问题及非 SPD 特征，不足以标定正式导数容差。完整原始矩阵不能交给 PCG。

## 修复方向与下一道关卡

在保留真实残差 merit 与物理接触公式的约束下，优先建立与残差兼容的 least-squares 方向：对当前固定 S，令 Jhat=S*(Dr/Dz)*S，求解 `(Jhatᵀ Jhat + λ I)y = -Jhatᵀ(Sr)`。λ>0 时矩阵 SPD，且对非零梯度，精确线性解具有负的真实 F 方向导数；λ=0 还需满列秩条件。近似线性解仍须检查下降性，并沿用真实 trial 验收。

位置 24 的冻结矩阵上，`JhatᵀJhat` 的 FP64 Cholesky 成功，所得方向与上述 least-squares 方向的相对差约 4.5e-15。这只是代数可行性，不能替代 GPU 实现、PCG 精度和完整轨迹证据。

正式实现前必须完成：解析或受控误差的 Jv/Jᵀv（包括法线、摩擦载荷和映射项）、与新算子匹配的预条件及尺度、固定线性/SPD 检查、双模式/graph 和事务回归，再在原预算下复验 Close。不能仅把原 GN 矩阵平方，也不能继续用旧的 -Sr RHS；它们不会自动补回缺失的真实导数。未选择把有限差分 dense oracle 静默加入 production。
