# Close 外层验收与 SPD/GN 方向审查 v4 — 2026-09-15

## 结论与范围

当前 SPD/GN 方向不保证实际残差 merit 下降。原步长条件隐含了近似精确 Newton 的下降速率假设；因此 PCG 成功与外层拒绝可以同时发生。但本次四个独立运行也表明：**在原重试全部失败后，仅放行一次被拒绝的步长，再恢复原策略，没有使该物理步恢复收敛。** 不能直接以“放宽单调性”作为已验证的修复。

本轮仅诊断原侧推 cube 的 Prepare/Close，最大 2500 步；在首次干预所在物理步结束后立即停止。不是抓取验证，不推进 Hold/Lift。保持原生产求解策略、物理参数、PCG 精度与 Newton 预算。实验继续使用研究开关 combined（cubic SDF + smooth history）与 production graph。

## 两种下降条件为什么不同

令当前迭代的尺度 S 固定，g=Sr，物理增量 p=Sy；B 是当前 SPD 近似矩阵（包含 regularization），PCG 近似解 `By=-g`。

- 对精确线性解，`gᵀy=-gᵀB⁻¹g<0`。若 r 确实是某个完整增量能量 E 的梯度，这才对应 `DE[p]<0`。
- 外层实际检查的是 `m=||Sr||/sqrt(n)`。设 `Jhat=S(Dr/Dz)S`，则光滑处 `Dm[p]=gᵀJhat y/(n*m)`；B 正定不决定这个符号。
- 无 regularization 的精确 Newton 满足 `Jhat y=-g`，这时 `Dm[p]=-m`。现有条件 `m_trial <= (1-1e-4*alpha)*m + merit_noise` 正好使用这一速率，而没有测量当前 SPD/GN 方向的实际导数。

这些推导以当前 S 固定、光滑分支为前提。实际 trial 使用当前尺度；下一次 `_evaluate_current` 会重新装配和更新尺度，所以 trial merit 与下一迭代 current merit 不能要求逐位一致。

此前 v1/v3 已在失败状态测到实际方向导数为正，且法向/摩擦缺项足以改变符号。若导数为正，仅继续缩步并没有一般性的下降保证；`merit_noise` 可以放过极小幅上升，却不能修复方向本身。即使导数为负，下降速度也未必符合上述精确 Newton 假设。

这里的 GN 是能量/接触切线的 PSD 近似，不能与残差最小二乘的 `JhatᵀJhat` 混为一谈。后者还需要对应 RHS `-Jhatᵀg`。

## 为什么不能直接换成总能量验收

v3 记录的材料能、法向罚能、局部摩擦 Huber 值并不构成已认证的完整增量能量：摩擦 cap、法线、history 转运和运动映射随 trial 更新，其力使用固定局部参数的导数；q 惯性、Coriolis 与完整动力学离散也不能直接用静态势能替代。

因此，“一些能量项下降”不证明完整残差对应的能量下降，更不证明最终 global/q/x 平衡达标。若选择能量路线，必须先建立与全部残差一致的增量目标，再讨论 SPD 方向的能量下降验收。不能只把现有局部 diagnostics 相加替换 merit。

## 证据支持的下一步

本次只排除了“最后 lambda=10 方向的一次放行足以恢复本次物理步”的设想。未测试持续的非单调窗口、信赖域、其他 regularization 的放行或新增 Newton 预算，不能声称所有非单调方法无效。

在继续保留当前物理残差的前提下，下一项有针对性的研究应在**同一失败状态**比较与实际残差兼容的方向和原 SPD/GN 方向：复用完整 Jacobian oracle，先验证真实下降与后续原 global/q/x 收敛，而不只验证一次 line search 通过。只有证明方向有用，才决定是否承担解析 Jv/Jᵀv、预条件与 GPU 开发成本。完整非对称 Jacobian 不能直接交给 PCG；最小二乘只是候选，尚未选定生产方案。

若另选一致能量路线，则首先明确摩擦/动力学离散，不能把该路线作为纯步长参数调整。本轮不改变默认策略、不放宽最终阈值，完整 Close 修复仍未完成。
