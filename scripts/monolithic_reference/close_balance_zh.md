## 结论

用户提出的解释得到部分支持：主要残差项已大幅相互抵消，而且现有 PSD/GN 方向确实可能在降低材料/法向罚能时被残差单调下降规则拒绝。此前仅凭残差方向导数上升就把方向称为“失效”、优先建议换成完整 Jacobian 的 least-squares 方向，证据不足。

但不能进一步断言“梯度已饱和、只剩浮点噪声或已达到可接受精度”：终止状态仍有可测量的力失衡，完整 FD 局部修正也不为零，主要能量项仍可继续下降。物理允许误差尚未标定。

本轮不更改接触、材料、PCG、Newton、line search、验收阈值或事务规则。不接受反事实试探步，只审查 Prepare/Close；抓取后续阶段仍暂停。

q 分为惯性、Coriolis、重力、外力、PD、limit、关节摩擦及接触；x 分为 consistent inertia、重力/外力、Smith 及接触。惯性部分用原 GPU kernel 在 scratch 中独立计算，逐次还原 scratch。残差分量重构与原始 residual 的缩放 RMS 差约 1e-11～1e-10，远小于终止 residual 的 1e-5 量级。

Smith 能量由独立 FP64 实现计算，并与 Warp 在变形单元上对照。consistent inertia/external 能量用相同质量系数计算。法向罚能使用实际接触 gap、原平滑公式、参考面积和刚度，在 FP64 累加。它是分项罚能，不是已经证明与整个接触 residual 共轭的全局势能。

保存三次相同零增量复算。能量重复值稳定，但这不能消除扰动状态本身的 FP32 坐标、法线和查询点量化误差：小到几十纳米的试探不用于可靠的能量符号结论，以下采用 alpha=1 和较大的试探。

## 主要项已相互抵消，但不是各项梯度都变小

定义分账比 `||S r||₂ / Σ_i ||S r_i||₂`，只是抵消程度指标，不是已标定的物理相对误差：

|终止状态|q 分账比|x 分账比|x 接触/Smith 分量的缩放 L2|
|---|---:|---:|---|
|位置 18|0.410%|2.113%|0.01257 / 0.01282|
|位置 24|0.834%|4.828%|0.01080 / 0.01094|

接触和材料梯度仍相当大，只是方向抵消。这里讨论的是包含惯性的动态步平衡，不是 cube 静止。

q 总量还可能遮蔽局部误差：位置 24 carriage 残差为 0.01427 N，相对于各项绝对值之和只有约 0.058%；但食指 MCP_FE、PIP、DIP 的残差分别约 1.606、1.111、0.531 mN·m，对应局部分账比约 4.52%、7.76%、10.23%。位置 18 这些关节约为 2.1%～2.2%。不能用 carriage 的大重力/PD 抵消程度代表所有手指都已收敛。q 同时含平移力和旋转力矩，原始 q 范数不解释为单一 N 或 N·m。

## 被拒绝的方向仍降低主要分项能量

下面是终止时原 PCG 方向，alpha=1。不是 FD 修正方向，也没有修改/关闭摩擦。

|量|位置 18|位置 24|
|---|---:|---:|
|残差 RMS，试探前|1.8496e-5|3.6095e-5|
|残差 RMS，试探后|1.9166e-5|4.2770e-5|
|Smith 能量变化 J|-2.3311e-7|-2.0643e-7|
|法向罚能变化 J|+6.8371e-8|-2.0660e-7|
|以上两项合计 J|-1.6474e-7|-4.1304e-7|
|x 增量惯性能量变化 J|+6.5697e-9|+1.1654e-8|
|x 重力/外力势变化 J|+2.8586e-9|+2.0971e-9|
|原 line search|拒绝|拒绝|
|试探最大节点位移|3.542 μm|6.182 μm|

alpha=0.5 也得到相同定性结论。全 residual 沿这些短试探路径的梯形积分 `Σ_i 0.5*(r_i(0)+r_i(δ))·δ` 为负，但它只是**单条路径的方向功近似**，不是路径无关势能的证明。

因此“真实 residual RMS 上升”不能等同于“物理能量上升”。若完整 residual 确实来自一个统一势能 E，SPD 近似 B 的方向 `δ=-B⁻¹∇E` 仍保证 `∇Eᵀδ<0`，无需完整不定 Hessian；残差平方的导数则不受此保证。当前观察到的拒步与这个区别一致。

当前系统还含载荷/法线/history 相关摩擦、关节限位阻尼、随构型变化的 M/C 等。未证明所有项来自同一个步内势能，也未完整记录这些项的势能。因此本轮不能宣称总增量能量下降，更不能直接改用“材料+法向罚能”作为全系统 line search。

## 剩余误差的物理量级

|量|位置 18|位置 24|
|---|---:|---:|
|cube 合残差力模 / 重量|1.83%|6.62%|
|仅按惯性平衡换算的 COM 速度修正模|约 0.180 mm/s|约 0.649 mm/s|
|完整 FD 局部 Newton 方向最大节点位移|54.1 μm|79.1 μm|
|其在 dt=1 ms 下对应的局部速度增量|54.1 mm/s|79.1 mm/s|

COM 换算使用 `-dt*Σr_x/m`，不是完整耦合重解。FD 方向也只是线性化的局部修正，不是已知真实解误差或误差上界；不能直接据此判定接受/拒绝。它们说明当前剩余量尚不能当作纯浮点噪声。不能仅因位移小于 SDF 空间误差就认定动态精度合格。

## 对修复顺序的修正

1. 保留当前 SPD/GN 接触近似作为有效候选。法线导数缺项是 residual Jacobian 不一致的来源，但并不单独证明必须换成完整 Jacobian 求解。
2. 优先审查外层 merit 与方向的匹配：完整增量势能是否可定义；或是否能在保持最终真实残差验收的前提下允许受控的非单调 residual 路径。任何方案先冻结定义、反例与失败规则，再做原预算 Close 复验。
3. 物理误差标定与算法 globalization 分开处理。现有证据不授权直接放宽 global/q/x 阈值，也不授权把“步长很小”替代残差收敛。
4. 完整 Jacobian least-squares/SPD 正规方程继续作为研究候选和 oracle，不再因“原方向使 residual RMS 上升”就确定为首选生产修复。
