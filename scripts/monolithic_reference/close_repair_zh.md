# Close 残差兼容修复试验 v5 — 2026-09-15

**状态：修复候选未通过；不进入默认生产路径，完整 Close 仍未修复。** 已实现并运行四类研究候选。目标加权能使两个测试物理步的 q 残差达标，但 global/x 仍超标；未以中间下降、较小步长或预算 soft-stop 代替最终验收。

## 范围与实现

研究入口 `run_close_repair.py` 在原侧推 cube 的首次 Close 失败物理步上尝试连续修正。主轨迹继续使用 combined（cubic SDF + smooth history）、production graph、actor_block；不推进 Hold/Lift，不把该场景作为抓取验证。

本轮没有将有限差分 dense 求解加入生产 solver。研究入口通过检查源码标记生成 `_iterate` 副本，保存实际执行的源码；正常路径保留原 PCG、regularization、line search、最终收敛及 small-step 规则。只有原重试全部无法找到下降步时，才切换研究方向。切换后在该物理步的剩余更新中继续使用研究方向，最多仍为 10 次 Newton 更新。

当前尺度 S 固定时，完整残差 Jacobian 的研究近似为 `Jhat=S*(Dr/Dz)*S`，`g=Sr`。沿用此前 oracle 的双侧有限差分：q 扰动 1e-4，x 扰动 1e-6 m（默认 multiplier=0.5），以实际可表示的 FP32 坐标间距作分母。每个候选状态重新计算完整力律，包括摩擦、法线和运动映射依赖；没有冻结或关闭这些力。

比较的方向及验收为：

1. **失败后完整 Jacobian 修正**：FP64 least-squares 解 `Jhat*y=-g`，使用原真实 global RMS 步长条件。它是研究 oracle，不是把非对称矩阵交给 PCG。
2. **从步初完整修正**：同一失败物理步回滚后，从第 0 次更新即使用该方向，仍只有 10 次更新。
3. **从步初阻尼修正**：用 `(JhatᵀJhat+lambda*I)y=-Jhatᵀg`，比较既有数值网格 `0/1e-4/1e-3/1e-2/0.1/1/10`。各 lambda 取首个通过原步长条件的 alpha，再选择实际 global RMS 最小者；最终重评所选 trial，重新检查后才接受。
4. **按最终目标加权的阻尼修正**（`--goal-weighted`）：搜索目标为 global/q/x 三个验收比的平方和，对应行权重 W；解加权最小二乘，并使用同一加权真实残差验收中间步。最终 global/q/x 阈值保持原值。这一分支允许原 global RMS 暂时上升，必须单独报告，不能称为沿用原 global 步长条件。

加权分支对每个块 b 的自由度 i 使用 `W_i² = 1/(n*T_global²) + 1/(n_b*T_b²)`，其中 T 是当前绝对+相对目标；统一归一化使最大 W 为 1。权重在每次 trial sweep 内固定，随下一次装配重新计算。预测方向与实际 trial 均使用这个目标，不只在候选排序时加权。对应 noise 为 `merit_noise*||W||₂`，是研究约定，未做正式噪声标定。

这些方法增加了 FD、dense 求解与候选试探成本；“Newton 预算保持 10”不意味着运行成本相同，也不意味着可以替代正式 GPU 实现。所有方向都检查有限值及预测下降；实际 trial 仍检查既有数值有效性。

## 同一步重放与失败边界

只有确认失败回滚后以下数组逐项完全相同，才重放该步：particle q/qd、joint q/qd、body q/qd，以及 committed history 的 valid/xi_local/normal_local。各分支的 `physical-input.npz` 额外保留控制 target q/qd，用于独立核对相同输入。重放使用同一个 solver 的原物理输入，不从已干预的 Newton 中间状态继续下一条物理轨迹。

研究分支结束后必须满足原最终 `SUCCESS`；原 `NONLINEAR_MAX_ITERATIONS` soft-stop 在研究干预后转为失败回滚，不能作为修复成功发布。原始状态与最终发布状态分别保存。每个分支结束即停止，不推进后续物理步。

位于 `close-repair-20260915-{18,24}-damping` 内的三个分支是同一步的比较；不同独立运行首次失败步可能不同，不跨目录宣称同状态对照。此前初版 `24`、`24-replay` 结果保留，不能替换为后续运行的数据。

独立运行目录为 `close-repair-20260915-{18,24}-weighted`；每个运行在其自身相同输入上比较“原重试失败后完整修正”和“从步初进行目标加权阻尼修正”。以下 global/q/x 仍是原最终验收比，没有使用加权搜索目标替代最终标准。

## 结论及剩余工作

现有 SPD/GN 与实际残差验收不匹配是可复现问题，但补入完整 FD Jacobian、提前介入、阻尼及目标加权均未在原预算内完成整个物理步。本轮没有一个候选通过正式集成所需的数值前提；先不承担其 GPU 后端开发成本，也不把 dense oracle 静默加入 production。

下一项诊断应锁定本次加权后 **q 已达标、x 仍停滞** 的实际状态，先核验 FD 尺度/可表示精度对剩余方向的影响，再区分真实非线性曲率、接触分支以及 residual 目标折中造成的停滞。当前证据不能证明该物理步不存在平衡解，也不能把剩余原因全部归为摩擦或材料。改变力律或时间离散需要单独说明物理含义，不能作为纯步长修补混入。
